# washopenresearch

## Agent skills

Configured for the `to-spec`, `to-tickets` and `implement` skills.

### Issue tracker

Issues live in GitHub Issues at `openwashdata/washopenresearch` (via the
`gh` CLI). See `docs/agents/issue-tracker.md`.

### Triage labels

Only the `ready-for-agent` role is in use, under its default label name.
See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `CONTEXT.md` at the repo root and ADRs in
`docs/adr/`. See `docs/agents/domain.md`.
