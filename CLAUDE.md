# washopenresearch

## Agent skills

Configured for the `to-spec`, `to-tickets` and `implement` skills.

### Issue tracker

Issues live in GitHub Issues at `openwashdata/washopenresearch` (via the `gh` CLI).

### Triage labels

Only the `ready-for-agent` role is in use, under its default label name.

### Domain docs

Single-context: one `CONTEXT.md` at the repo root and ADRs in `dev/adr/`. `docs/` is the build folder of the package site and is not committed, so nothing is kept there.
